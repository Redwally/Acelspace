# ACELSPACE

Site web du club.

## Prérequis

- Node.js 18 ou supérieur
- npm

## Installation

```bash
npm install
cp .env.example .env
```

Renseigner les valeurs dans `.env`.

## Développement

```bash
npm run dev
```

## Build

```bash
npm run build
```

Le résultat est généré dans `dist/`.
